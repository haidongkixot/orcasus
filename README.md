# Orcasus Agent Team System v2.2.0

Complete Claude Code Agent Team workspace for complex web/mobile applications. Includes project configuration, 15 role agents, 9 skills, debate and voting, Team Secretary, recording hooks, readiness gates, zero-capture testing defaults, templates, validation scripts and documentation.

Start here: INITIALIZE_AGENTS.md. Read CLAUDE.md and .claude/settings.json before use. Run scripts/test_meeting_logger.py and scripts/validate_bundle.py, then follow docs/ACCEPTANCE_TESTS.md in a non-production workspace.

Agent Teams are experimental and consume more tokens than a single session. Hook configuration is not proof of runtime capture. Screenshot, trace and video budgets default to zero. Missing resources and permissions require owner review rather than silent workarounds.

Official docs: https://code.claude.com/docs/en/agent-teams ; https://code.claude.com/docs/en/skills ; https://code.claude.com/docs/en/hooks ; https://code.claude.com/docs/en/permissions ; https://playwright.dev/docs/api/class-testoptions
